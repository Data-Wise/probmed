## Phase 0 — Diagnosis (COMPLETE, this session)

The prior question behind #32 was: *why does the percentile bootstrap arm sit at
coverage 1.00 in every cell?* Answered from existing artifacts
(`inst/sim/results/gauge_boot_coverage_nsim2000.csv`), no new compute.

`seW_bt_ratio` = `mean(seW_bt) / sd(W)` (collate_gauge_boot.R:12) — mean bootstrap
SD over the empirical SD of `W` across reps. Nominal coverage 0.95:

| n | binY | tau | seW_an_ratio | seW_bt_ratio | covW_an | covW_pct |
|---|---|---|---|---|---|---|
| 800 | F | 0.0 | 0.65 | 1.41 | 0.867 | 1.000 |
| 3000 | F | 0.0 | 0.71 | **0.99** | 0.859 | 1.000 |
| 800 | F | 0.8 | 0.72 | 1.28 | 0.899 | 1.000 |
| 3000 | F | 0.8 | 0.83 | **1.07** | 0.913 | 1.000 |
| 800 | T | 0.0 | 0.72 | 5.06 | 0.879 | 1.000 |
| 3000 | T | 0.0 | 0.74 | **1.17** | 0.869 | 1.000 |
| 800 | T | 0.8 | 0.74 | 16.62 | 0.892 | 1.000 |
| 3000 | T | 0.8 | 0.67 | **0.97** | 0.874 | 1.000 |

**Two findings.**

1. **The analytic arm's problem is confirmed and correctly diagnosed in the
   manuscript.** `seW_an_ratio` is 0.65–0.83 in all 8 cells: the influence-function
   SE under-estimates the empirical SD by 17–35%, so the symmetric Wald interval
   under-covers (0.86–0.91). Nothing to change here.

2. **The percentile arm's problem is NOT over-dispersion, and NOT (only) skew.**
   In the four `n = 3000` cells the bootstrap SD is essentially exactly right
   (0.97–1.17x empirical SD) — yet coverage is still 1.000. Correct dispersion with
   1.000 coverage is only possible if the resample distribution is **heavy-tailed**:
   the 2.5/97.5 percentiles sit far outside 1.96 SD, so the percentile interval is
   far wider than the sampling distribution warrants, while its SD matches.

   The mechanism is the ratio itself. `W = R/OE` divides by an estimated `OE`; a
   bootstrap resample that draws `OE` near zero produces an enormous `W`. Those draws
   fatten the tails without necessarily inflating the SD. At `n = 800` with a binary
   outcome they are frequent enough to inflate the SD too — hence the 5.06 and 16.62
   cells, which are the *same* mechanism in a more acute regime, not a separate bug.

**Consequences.**

- The manuscript's stated explanation ("the ratios are skewed, so use a tail-aware
  percentile interval") is the right diagnosis of the *analytic* arm's failure but
  the wrong prescription: the percentile interval does not fix a ratio with an
  uncertain denominator, it merely widens until it (vacuously) covers.
- **This closes #32 on the merits.** BCa's acceleration constant is a skewness
  correction estimated from the influence function's third moment; it reshapes
  endpoints under skew. It does not tame heavy tails generated by a near-zero
  denominator, and BCa's own `z0`/`a` estimates degrade under exactly those extreme
  draws. BCa is not the fix for what is actually wrong here.
- The principled construction for a ratio with an uncertain denominator is
  **Fieller**, which `ward_residual()` *already computes* for `P_med` (`fieller =
  TRUE`) and which the manuscript's own Application section uses to show the `P_med`
  set is the entire real line when `OE` is null. The percentile bootstrap's 1.00
  coverage is a blurred version of that same message — an interval that is very wide
  rather than honestly unbounded.

## Phase 2 — probmed: Fieller set for `W`

**Code change — `dev` blocks new logic, so this needs a feature branch.**

`ward_residual()` computes the Fieller set for `P_med = IIE/OE` only
(`R/gauge-pmed.R:363-385`). `W = R/OE` has the identical structure — same
denominator, same influence-function machinery already computed (`pR`, `pOE`) — and
is the ratio the manuscript actually foregrounds.

- Add `W_fieller` / `W_fieller_type` to `GaugePmedResult`, computed by the existing
  quadratic-inversion block generalized over (numerator influence, denominator
  influence).
- Surface in `print()` alongside the `P_med` set.
- Tests: bounded / exclusive-unbounded / all-real branches for `W`, mirroring the
  existing `P_med` Fieller tests.

**Open design question for this phase:** does the Fieller set *replace* the
percentile bootstrap as the recommended interval for `W`, or sit beside it? The
Phase 0 evidence says the bootstrap arm is not doing what the manuscript claims, but
"report Fieller instead" is a recommendation change with manuscript consequences —
decide before Phase 4, not during it.

**Effort:** ~half day including tests.
