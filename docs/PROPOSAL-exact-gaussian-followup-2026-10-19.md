## Scope and source audit

The existing `inst/sim/hopper/i6/runner.R::exact_pmed()` fits `M ~ X` and `Y ~ X + M` on each bootstrap sample, then evaluates `Phi(ab / sqrt(2(b^2 sigma_M^2 + sigma_Y^2)))`. It uses residual scales from `SSE/df.residual`, as in those bootstrap refits. For additive Gaussian models with treatment contrast `delta = x_value - x_ref`, the numerator is `delta*a*b`; direct effect and shared covariates cancel when both potential outcomes hold treatment and covariates fixed. The formula requires the independent nested-outcome coupling used by the simulation. It does not establish joint A2 or support binary, ordinal, count, interaction, heteroscedastic, or arbitrary SEM models. Reject nonfinite fits and specify the deterministic/tie boundary when the denominator is zero.

The manuscript simulation's nonparametric percentile interval, the package's default **parametric** bootstrap, and its opt-in **model-based response** bootstrap use different resampling laws. Currently `R/compute-core.R`, `R/compute-bootstrap.R`, and `R/compute-model-bootstrap.R` call the simulated single-mediator core; the parallel Gaussian path has a separate closed-form kernel. I6 e validates none of those package methods automatically. Do not globally replace `.pmed_core_simple()` or change a public default from this result. A package API change needs a separate feature branch and method-specific tests and documentation.

**Latest cross-package boundary (checked 2026-10-20).** medfit `main`/`dev` is 0.11.0 and supplies model fitting, named path/covariance extraction, and a generic `bootstrap_mediation()` statistic callback. probmed still declares `medfit (>= 0.3.0)` and owns its own `PmedResult` and bootstrap implementations; the generic medfit routine is not evidence that the proposed exact kernel has been integrated. RMediation `dev` is 1.7.0, with 1.7.1 on a separate release branch. Its `ci(MediationData)` estimates intervals for the path product `a*b`, and its SEMFit `mbco()` compares constrained indirect-effect models. Neither is an independent numerical oracle or a drop-in confidence interval for tie-adjusted `P_med`. Record the actual installed dependency versions before any package test; do not infer a published release from a development branch.

**Completed pmed evidence, not a new probmed validation.** The pmed source-verification report `docs/reports/EDIT-REPORT-pmed-exact-gaussian-2026-10-19.md` in the pmed repository records Hopper job 4342657 at `/users/dtofighi/probmed_exact_20261019_full_e`: seed base `20261021`, 600 chunks, 120,000 outer rows (6,000 per 20 cells), and 2,000 nonparametric bootstrap estimates per row. This plan review relies on that report, not a fresh raw-chunk audit. The later 94% minimum was chosen after the run; at least one reported cell's 94.38% observed coverage is below that alternative rule's 94.52% observed threshold. That post hoc comparison does not alter the original gate or its result. 2. **Prove the numerical kernel independently, locally.** Derive the normal-difference formula on paper, including `delta`, direct-effect cancellation, shared-covariate cancellation, and the zero-denominator tie case. Compare an implementation using the extracted coefficients and residual scales with an independently coded one-dimensional integral `E_D[Phi(b*D/(sqrt(2)*sigma_Y))]`, where `D ~ N(a*delta, 2*sigma_M^2)`, on fixed parameter fixtures; require absolute error <= `1e-8`. Include positive/negative a and b, reversed/non-unit treatment contrasts, zero a or b, unequal residual scales, factor covariates, and a direct-effect perturbation. Check supported-family/structure guards. Test a forced nonfinite refit and require explicit failed-draw accounting rather than `na.rm=TRUE` silently discarding it. Keep MBCO's likelihood MLE scale distinct from the bootstrap's residual-df scale.
3. **Replay retained evidence as a regression check.** Select two outer replications per I2 and I6 Gaussian cell, including s6/N=1000 and edge cases, before inspecting their replay results. Reconstruct their datasets and bootstrap-index streams from the recorded seeds and worker topology; compare all selected exact point estimates and interval endpoints by `(scenario,N,rep)`, requiring no missing selected key and max absolute difference <= `1e-12` on identical resamples. Independently scan the *stored* I2/I6 output grids for full key completeness, finite intervals, and hashes; avoid recomputing all 130 million retained bootstrap fits solely for this regression check. The replay checks source integration and provenance, not independent coverage. Confirm fixed-data scores against high-precision direct simulation as a separate sanity check.
4. **Verify and report the original acceptance decision.** For the six s6/s7-by-N cells at N = 250, 500, 1000, reproduce the frozen rule: each cell's **two-sided 90% exact-binomial interval** for empirical coverage must lie entirely inside **93%–97%**. This is the rule used for the completed pmed run; do not substitute a one-sided lower-bound test or average across cells. Check every chunk hash, expected replication key, bootstrap count, finite interval, and failure count before relying on the result. Count incomplete outer intervals as noncoverage and report them separately; do not drop them from the denominator. Report per-cell coverage, Monte Carlo SE, exact-binomial interval, mean width, and point-estimate behavior. Width is descriptive and merits separate scrutiny, not a hidden additional gate. Small-N s6 overcoverage and s1/s8 results remain per-cell disclosures outside the six-cell acceptance claim. If the frozen gate cannot be reproduced or source integrity fails, withhold the acceptance statement and investigate; do not change the gate or add replications to rescue it.
5. **Package work stays separate.** If the author chooses package integration, first define whether exact Gaussian evaluation applies to `plugin`, parametric, nonparametric, or model-based bootstrap, and preserve each method's resampling law, result slots, convergence/failure semantics, and seeded behavior. Make it opt-in or versioned until the behavior and `n_sim` meaning are reviewed.
